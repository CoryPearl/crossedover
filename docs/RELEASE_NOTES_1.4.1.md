# crossedover v1.4.1 — Settings search

Version **1.4.1**, build **27**.

- Search Settings by name or topic, including graphics, downloads, Minecraft,
  backups, recovery, runtime and diagnostics. Multiple words narrow the results.
- Matching Advanced controls appear automatically. Clearing search restores the
  previous Advanced disclosure state.
- The search field stays visible while scrolling. Press **⌘F** in Settings to
  focus it; use Escape or the clear button to restore all settings. Clicking
  elsewhere leaves the field. Games and Apps retain independent library search.
- Search changes return results to the top while retaining native scrolling.

The DMG includes the same Windows runtime and separate Minecraft backend as
v1.4.0. This update changes the Mac interface; the confirmed CS2 graphics,
window controls and normal Steam/VAC launch path are preserved.

Apple silicon and Rosetta are required. Steam/Epic/.exe support targets macOS 15
or 26; Minecraft requires macOS 26+ and an owned Windows edition. No games,
accounts or saves are bundled. The app is locally signed, **not Developer ID
signed or notarized by Apple**. Downloads require repository access while the
GitHub repository is private. Existing compatibility and
[release validation limits](RELEASE.md) still apply.
