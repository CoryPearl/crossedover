BEFORE YOU DOWNLOAD

A few honest answers.

Will every Steam game work?

No. Compatibility is experimental. TrackMania Nations Forever is the first tested demo, CS2 is experimental, and other titles are untested. Performance and long-session stability vary.

Are games included?

No game files or accounts are included. Windows Steam downloads directly from Valve; you install games through your own account. Your native Mac Steam client stays separate.

Where do the games go?

Games and runtime data live separately from the app under ~/Library/Application Support/CrossedOver/. Use a game’s ⋯ menu to show its files or request an uninstall in Steam.

What should I know before installing?

You need Apple silicon, macOS 15 or 26, Rosetta 2, and 8 GiB free before game downloads. This release is not notarized. Read the quickstart. While the repository is private, downloads require GitHub repository access.
