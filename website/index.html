GET GOING

A short setup.
Then, your library.

Read the quickstart ↗
  1. 1

    Make it at home

    Open the DMG, then drag crossedover into Applications. You’ll need Rosetta 2 and room for your software. The Windows runtime and Minecraft backend are included.

  2. 2

    Choose a launcher

    Use Game Launchers for Steam, Epic, or Minecraft in v1.4.0. Choose Add .exe for other Windows software. Sign in through each launcher’s own window.

  3. 3

    Pick something to play

    Installed games, including Minecraft in v1.4.0, appear in Games. Added executables get a card in Games or Apps. Press Play or Run; use ⋯ for files and management. Epic verification and uninstall continue in Epic’s Manage menu.

BEFORE YOU DOWNLOAD

A few honest answers.

Will every Windows app or game work?

No. Compatibility is experimental. TrackMania, Brawlhalla, CS2, and Minecraft have local test evidence. Other apps and games may need dependencies or be unsupported. Performance and long-session stability vary.

Can I use my Epic library?

Yes. Choose Game Launchers → Set up Epic Games to install the Windows launcher, sign in there, and download a game inside its Windows C: drive. Completed installs appear beside Steam games. Epic games use their Windows launcher, with DXMT / Metal for DirectX 10–11 and DXVK / Metal for DirectX 9. Games installed through Ubisoft Connect, such as Brawlhalla, retain their Epic card and launch through Epic’s own partner handoff after initial account linking. See the Epic guide.

Can I play Minecraft Bedrock?

Yes, in the v1.4.0 release with its included Minecraft backend. Sign in with the Microsoft account that owns Minecraft for Windows, install it, and launch from its Games card. Verified download/install and local play with controls, sound, and saving have been tested. It needs Apple silicon, macOS 26+, and Rosetta. The Windows Xbox app and general Game Pass catalog are not implemented. Minecraft setup ↗

Can I run an .exe without Steam?

Yes. Choose Add .exe, give it a name, and place it in Games or Apps. Add its containing folder when it needs nearby files. Run installers first, then edit the card to choose the installed program. Everything runs locally with your Mac user permissions. See the .exe guide.

Can I add mods?

Use a game’s ⋯ → Mods & files menu to open its installation or Windows Documents in Finder. Follow each mod’s Windows instructions. Steam Workshop subscriptions are available for games that support them; Windows mod managers and DLL loaders may need additional setup. See the modding guide.

Are games included?

No game files or accounts are included. Steam and Epic use their official Windows clients. Minecraft is downloaded from Microsoft after ownership checks in v1.4.0. Install games through your own accounts. Your native Mac launchers stay separate.

Where do the games go?

Games, imported apps, and runtime data live separately from the app under ~/Library/Application Support/CrossedOver/. Use a game’s ⋯ menu for its files or uninstall flow. Epic uninstall continues in Epic Library → ⋯ → Manage.

What hardware do I need?

Apple silicon (M1 or newer), macOS 15 or 26, working Rosetta, and 8 GiB free for setup plus game storage. We recommend 16 GB+ unified memory, or 24–32 GB+ for heavier games, and SSD space for updates. M4 / 16 GB is our current test configuration; other Macs and a minimum 60 FPS have not been validated. Read the hardware guidelines.

What should I know before installing?

You need Apple silicon, macOS 15 or 26, Rosetta 2, and 8 GiB free before game downloads. This release is not notarized. Read the quickstart. While the repository is private, downloads require GitHub repository access.
