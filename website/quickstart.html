CROSSEDOVER · V1.4.0

Get started.

A few minutes of setup. Then, your Windows apps and games.

Before you start

You need an Apple silicon Mac, macOS 15 or 26, Rosetta 2, an internet connection for setup. Use your own store accounts, or an owning Microsoft account for Minecraft. Minecraft’s separate backend requires macOS 26+. Allow 8 GiB free for setup, plus space for apps and games. Recommended: 16 GB+ unified memory, or 24–32 GB+ for heavier games. Hardware guidelines.

v1.4.0 is the Minecraft release in development. It adds local Minecraft Bedrock alongside Steam, Epic, Ubisoft handoffs, and .exe cards. Microsoft sign-in, verified install, and local play with controls, sound, and saving have been tested. The download below is the previous v1.3.1 build.

1. Make it at home

  1. Download crossedover v1.3.1 and open the DMG.
  2. Drag crossedover into Applications.
  3. Eject the disk image and open crossedover from Applications.

First open

This release is locally signed and not notarized by Apple. If macOS blocks it and you trust this download, try opening it once, then use System Settings → Privacy & Security → Open Anyway. Confirm the app name. Follow Apple’s instructions; do not disable Gatekeeper system-wide.

If macOS offers to install Rosetta 2, follow Apple’s prompt.

Add a Windows .exe

Games holds Steam/Epic installs, Minecraft after setup in v1.4.0, and Windows games you add yourself. Apps holds tools, installers, mod managers, and other Windows software.

  1. Choose Add .exe (⌘O) and select a local x86 or x64 Windows executable.
  2. Name the card and choose Games or Apps.
  3. Enable Include files from the containing folder when it needs nearby DLLs, assets, or installer data. Extract archives first; use a folder containing only that app.
  4. Choose Add to library, then Play or Run on the card. Steam is optional; the first import prepares the included runtime.

External files are copied into the Windows environment’s C:\crossedover\Apps folder. Files already inside C: are used in place. Nothing is uploaded. Apps run with your Mac user permissions: add software you trust. Windows ARM executables, DLLs, and incomplete images are rejected. Compatibility varies, including with apps that need extra frameworks or drivers.

Installers: run the installer card and finish setup. Then choose ⋯ → Edit app / choose executable → Choose and select the installed program inside C: (usually Program Files). Save the card to run the program next time.

Use ⋯ to rename, change the executable, move between libraries, browse files, or view the launch log. Remove from library removes only the card, keeping its files. To uninstall installed Windows software, run its supplied uninstaller from C:. Delete unused portable app folders in Finder after closing Windows apps. Settings → Windows C: drive → Open in Finder opens the environment. Full app/data uninstall includes these managed files; your original files outside the environment stay on your Mac.

Steam

  1. Choose Game Launchers → Set up Steam. The app prepares its included runtime and downloads Windows Steam directly from Valve. Allow a few minutes.
  2. Sign in inside Steam’s window, completing Steam Guard if requested.
  3. Install a Windows game through that Steam client.

Your native Mac Steam installation stays separate. No accounts, game files, or saved games are bundled with crossedover.

Bring in Epic Games

  1. Choose Game Launchers → Set up Epic Games. crossedover downloads Epic’s official Windows MSI installer and installs its Windows launcher. Steam is optional.
  2. Sign in inside Epic’s own window and complete any two-factor prompt.
  3. Download a Windows game to its default folder or another location inside the managed C: drive.
  4. Completed installs appear in Games with an Epic Games label. Refresh with ⌘R; use the All games / Steam / Epic Games / Added .exe filter.
  5. Press Play on the card. The launch goes through Windows Epic for account authorization and DRM.

Game Launchers in the sidebar groups Open Steam, Open Epic Games, Open Ubisoft Connect, and Minecraft Bedrock…. Steam and Epic offer setup when missing. Ubisoft Connect is enabled after a supported Epic game installs it. Your native Mac clients stay separate. Epic uses DXMT / Metal for DirectX 10–11 and DXVK / Metal for DirectX 9 when available; Steam and directly added apps keep their chosen graphics profile. Game compatibility, DRM, anti-cheat, and extra dependencies still vary.

Epic cards offer Game properties, Show game files, Mods & files, and Manage in Epic. Verify files in Epic and Uninstall in Epic open Epic Library: find the game and choose ⋯ → Manage → Verify / Uninstall, then confirm there. These actions open the management flow; they do not silently verify or delete files. The card disappears after uninstall finishes and the library refreshes.

Settings → Windows Epic Games → Open download folder opens the default C:\Program Files\Epic Games folder in Finder. Per-game file access uses its actual install location. Epic downloads → Open Epic opens the client; use its Downloads control for pause/resume, updates, and progress.

Setup also installs Epic’s required launch-support components. If an existing installation opens Epic but no game, quit Windows games and launchers, then choose Settings → Windows Epic Games → Repair launch support. Games and accounts are preserved. First-time setup may download an additional 85 MB component. Repair verifies the helper; each game still needs a launch test.

Use your libraries

Completed Steam/Epic installs and Minecraft after setup in v1.4.0 appear in Games. Imported .exe cards can live in Games or Apps. Press Play to launch, ⌘R to refresh, or ⌘F to search. The grid/list selector remembers your preference. If the app requests a graphics-profile restart, close your current game first.

Use ⋯ for properties, files, verification, and uninstall. Steam handles uninstall confirmations. Settings → Windows Steam → Open download folder opens installed games in Finder. The separate Steam Downloads button opens download progress and updates.

The bottom launch bar shows preparing, waiting, and running status without an estimated percentage. Stop & close Windows cancels a launch and closes all crossedover Windows games, apps, and launchers. Unsaved progress may be lost and downloads interrupted. Native Mac launchers stay separate.

Know what’s experimental

TrackMania, Brawlhalla, CS2, and Minecraft Bedrock have local test evidence. The owner confirmed CS2 menu clicks align after moving to a larger monitor. Minecraft local controls, sound, saving, and normal quit are confirmed. Those checks do not certify every app, game, feature, or Mac. Compatibility, performance, and long-session stability vary.

Mods & game files

Quit the game before changing files. Choose ⋯ → Mods & files → Game folder to open its installation in Finder, or Windows Documents for games that store maps, skins, or mods there. Copy extracted mod files into the location required by the mod's Windows instructions.

In Windows Steam, use the game's Properties → Installed Files → Browse to open its files in the runtime's Windows file explorer. Both routes access the same installed files.

For games that support Steam Workshop, subscribe in Windows Steam and let downloads finish. Enable items in the game if needed. Windows mod managers, script extenders, DLL loaders, and additional frameworks may need separate setup; their .exe files can be added as App cards, but crossedover does not automatically configure their extra dependencies. Game updates and verification can replace modified files. Keep copies of files you replace yourself.

The managed Steam host is labelled crossedover Steam in macOS. For an older installation, quit Windows Steam and all games, then choose Settings → Advanced → Use included runtime after updating the app. Reopen Steam to apply the label. Game names and descriptive dialog titles stay intact.

Choose your graphics

Installed game cards and list rows show a Recommended renderer, or a Starting point if the graphics API could not be identified. Click it or choose ⋯ → Graphics recommendation… to see the basis and current renderer. Applying a Steam recommendation requires all Windows software to be closed; Steam and added apps share this setting. Epic/Ubisoft manage their own combination; Minecraft uses its separate DXMT environment. Import hints do not guarantee compatibility, and DirectX 12 is unavailable.

CS2 targets 60 FPS with a 1280×720 launch window and a one-time low-detail preset: MSAA and ambient occlusion off, lower scene detail, with dynamic shadows, sound and window/input fixes retained. Later in-game choices are preserved. FSR stays disabled for clarity. Fullscreen can increase render resolution on a larger display, so check Video settings before comparing match FPS. A frame cap is not a guaranteed minimum. Only a small original settings file is retained; no full environment backup is made.

Settings → Graphics renderer explains each mode. Quit all Windows software before changing it. Your saved choice stays selected after updating; the old Legacy, Performance, and Metal names now appear as OpenGL fallback, DirectX 9, and DirectX 10–11.

  • DirectX 9–11: DXVK for DirectX 9 plus DXMT for DirectX 10–11, both through Metal. Useful for mixed libraries and apps with components using different versions. Requires both runtime components.
  • DirectX 10–11: DXMT and Metal for software requiring those versions; DirectX 9 uses the OpenGL fallback.
  • DirectX 9: DXVK and Metal for software requiring DirectX 9 without the DirectX 10–11 path.
  • OpenGL fallback: WineD3D for older DirectX software. Try it for visual errors or startup failures with Metal; performance and feature support are more limited.

Only supported modes are selectable. Epic and Ubisoft manage their own renderer combination. These modes do not add DirectX 12 support. Choose resolution, visual detail, and frame limits inside each app or game; known compatibility presets may still apply.

If CS2 reports missing or invalid signatures, quit the game and choose ⋯ → Verify game files…, then check Steam’s progress. An offline Practice match alone does not validate VAC-secured play. Steam’s file verification instructions.

The latest v1.4.0 CS2 test confirms working native window controls, online matchmaking and satisfactory performance on the tested M4 after restoring Steam’s normal overlay handling. The preset targets 60 FPS; an automated sustained minimum has not been measured. Retained Windows environments share one library, with each game opening from its original environment. The preferred environment supplies duplicate titles and receives new installs; existing games do not need to be copied or downloaded again.

Your files

The app is in /Applications/crossedover.app. Games, imported apps, runtimes, saves, Windows Steam and Epic, and backups live separately under:

~/Library/Application Support/CrossedOver/

Use Open download folder to browse your games, or ⋯ → Show game files for one game. Environment backups are manual only and cover the selected default environment, including its games, apps, and imported cards. Other retained environments remain separate. Restoring a pre-v1.1.0 backup clears imported cards because that version did not have them. Small copies of changed settings are kept for recovery. Use Settings → Backups → Create backup for a manual copy. Clear backups, beside it, moves old full backups to Trash while keeping current games and saves. Empty Trash in Finder to reclaim space; APFS clones can share blocks.

Uninstall everything

Quit Steam, Epic, games, and Windows apps, then choose Settings → Uninstall crossedover → Uninstall app and data. This moves the app, its Windows Steam and Epic clients, managed games and apps, local saves, runtimes, and backups to Trash, clears preferences, and quits. Export local saves you want to keep first, then empty Trash to reclaim space. Your separate Mac Steam library is unaffected.

Dragging only the app to Trash leaves its separate data folder behind. Use the in-app uninstaller for complete removal. Custom data locations and apps opened from a read-only DMG must be managed in Finder.

Need a hand?

  • Missing game: wait for installation to finish, then press ⌘R.
  • Slow first launch: check Steam for a prerequisite or setup dialog.
  • Frozen game: try ⌘Tab and quit normally. Recovery tools are in Settings → Advanced. Force quit can lose unsaved progress.
  • Reporting a problem: save a diagnostic report, review it, and open an issue. Never share passwords or Steam Guard codes.

Epic games that use Ubisoft Connect

Some Epic titles, including Brawlhalla, delegate installation to Ubisoft Connect. crossedover combines Epic’s partner records with Ubisoft’s completed install registration. These games appear as Epic Games cards; Play asks Epic to launch them, preserving Epic’s own authorization and Ubisoft handoff. Complete initial account linking in Epic’s own Library first. Independent Ubisoft installations appear under Ubisoft Connect. Sign in and link accounts in the launcher's own window if asked. Play routes through the owning launcher; verification and uninstall continue in Ubisoft Library. Per-game files and mods open in Finder. Other titles remain untested.

Ubisoft's launcher uses DXMT / Metal, with DXVK / Metal for DirectX 9 software when available. Steam retains its saved graphics profile. A running process does not establish a visible window or playable game.

Minecraft Bedrock · v1.4.0 preview

Minecraft runs locally through its own WineGDK backend. The current Mac has passed Microsoft sign-in, verified download/install, local play with working controls and sound, saving, and normal quit. Broader hardware, multiplayer, updates, and long-session performance still need testing. The previous v1.3.1 download has no Minecraft backend.

  1. Use a v1.4.0 build containing the separate Minecraft backend. It requires Apple silicon, macOS 26+, Rosetta, an owned Minecraft for Windows edition, internet, and at least 8 GiB free for setup.
  2. Choose Game Launchers → Minecraft Bedrock… → Install & Play.
  3. Complete Microsoft sign-in and any Keychain permission prompt in their own windows. No credentials belong in chat or crossedover’s library.
  4. Keep setup open while the download is verified and installed. After completion, Minecraft appears as a Games card or list row. Use Play on later launches, or ⌘R to refresh.

Minecraft’s launcher options open game files/worlds, sign out, or uninstall the game while keeping worlds. Stop Minecraft affects only its separate session; Steam, Epic, and imported apps keep their own environment. Export worlds before a complete app/data uninstall. No Minecraft game or account is bundled.

Xbox and Game Pass

The Windows Xbox app and general PC Game Pass catalog are not implemented. Minecraft’s specific backend does not provide general Xbox compatibility. Settings → Other platforms → Open Xbox Cloud opens Microsoft’s streaming site for eligible games/accounts; it creates no local installation. Minecraft Java has a separate native Mac edition.

Required & recommended hardware

These guidelines cover the included runtime. Recommendations are planning guidance, not measured minimums or a promise of 60 FPS.

Choose a Mac for your Windows apps and games

macOS 15 or 26, with working Rosetta / Intel translation.macOS 26 is the current test environment. macOS 27 is experimental; the current runtime blocks macOS 28 and later. Apple’s Rosetta guidance.

A title compatible with the runtime, and the controls it requires.Start at 720p or 1080p with low/medium detail. On a laptop, connect power and use Automatic energy mode for sustained gaming. Apple’s power-mode guidance.

An 8 GB Mac is not a validated gaming configuration. Current testing uses an Apple M4, 16 GB unified memory, and macOS 26.6.2. A short TrackMania race reached roughly 55–60 FPS with tuned settings; that does not establish a minimum, long-session stability, or performance for other games or Macs.

The setup allowance excludes game downloads and manual backups. The app and its Windows data are separate; a full backup can need space for the whole Windows environment. Faster hardware cannot supply unsupported Windows features, DRM, or anti-cheat.
